## 🔧 トラブルシューティング

### よくある問題

1. **APIキーが設定されていない**
   - エラー: `OpenAIError: The api_key client option must be set`
   - 解決: 環境変数 `OPENAI_API_KEY` を設定

2. **ライブラリがインストールされていない**
   - エラー: `ModuleNotFoundError: No module named 'yfinance'`
   - 解決: `pip install yfinance pandas openai`

3. **仮想環境が有効化されていない**
   - 確認: コマンドプロンプトに `(venv)` が表示されているか
   - 解決: `.\venv\Scripts\Activate.ps1`
